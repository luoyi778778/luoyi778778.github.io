# 落以的个人主页 (Luoyi's Portfolio)

> 单页响应式个人主页，采用现代化的“玻璃拟态 (Glassmorphism)”设计风格，并结合互动粒子动画。本项目部署于 GitHub Pages，全程采用 **AI 辅助开发** 模式构建。

🌍 **线上地址**：[https://luoyi778778.github.io/](https://luoyi778778.github.io/)

---

## 🎨 项目特色

本项目旨在通过最纯粹的前端原生技术，打造出令人眼前一亮的视觉体验：

- **✨ 动态粒子背景**：基于 Canvas 绘制的随机漂浮气泡粒子，呈现呼吸感与深邃的视觉空间。
- **🧊 极致玻璃拟态**：运用 `backdrop-filter` 实现精致的磨砂玻璃卡片效果，结合半透明背景与微边框，现代感十足。
- **🎬 丝滑交互动画**：
  - 页面加载时的 3D 旋转开页效果与平滑淡出。
  - 基于 `IntersectionObserver` 的按需加载入场动画（支持四个方向的平滑滑入）。
- **📱 全端响应式设计**：完美适配 PC 桌面、平板及移动端设备（响应式断点 860px/680px）。
- **🎨 设计系统**：高度可配置的 CSS 变量（Variables）系统，轻松管理主题色、阴影和圆角等设计 Token。

### 🤖 AI 辅助开发模式

本项目是由人类开发者与 AI 深度协作的成果，采用了**多 AI 工具协同**的开发链路：

1. **Claude Code CLI**：作为主力构建者，负责搭建页面基础框架、构建 CSS 设计系统及实现复杂的 Canvas 粒子动画。
2. **DeepMind Agent (Codex)**：作为代码优化与排版重构专家，负责审阅代码质量、调整响应式布局排版（如精准的对称网格布局）并不断打磨交互细节。
3. **人类开发者**：梳理产品需求，把控整体设计审美，指挥 AI 工具并进行最终微调。
